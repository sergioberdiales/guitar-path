# Guitar Path

## Reglas del proyecto

- La aplicación debe ser estática y compatible con GitHub Pages.
- Usar Vite, JavaScript vanilla, HTML y CSS.
- No usar React, TypeScript ni otros frameworks sin una decisión explícita posterior.
- No añadir inicialmente backend ni base de datos.
- Minimizar las dependencias.
- Mantener el contenido pedagógico separado del código de la aplicación.
- Trabajar de forma incremental y no implementar funcionalidades que aún no estén definidas.
- Priorizar código sencillo, comprensible y mantenible.
