# Currículo

Un bloque agrupa varias semanas por tema, sin duración fija. Cada semana contiene exactamente dos sesiones guiadas. Las sesiones se numeran de forma correlativa en todo el curso y son la unidad de práctica y seguimiento.

El recorrido previsto es de unas 24 semanas. Solo se publican contenidos disponibles; no se crean sesiones vacías.
